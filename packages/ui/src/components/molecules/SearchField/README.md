Campo de pesquisa de zona com rótulo e ícone `search`. Props: `id`, `label` (por omissão "Procurar zona"), `placeholder`, `hideLabel` (mantém o rótulo para leitores de ecrã), `value`/`defaultValue`, `onChange`.

- Em mobile use `hideLabel` quando o espaço for curto; o `placeholder` não substitui o rótulo.
