Agrupa `Label`, um controlo (`TextInput` ou `Select`) e uma mensagem de erro opcional. Props: `id` (igual ao do controlo), `label`, `hint`, `error`, `children`.

- O erro tem ícone e texto (nunca só cor).
- Largura 100% do contentor; o layout (colunas) é decidido por `CalculatorForm` e pelas páginas.
