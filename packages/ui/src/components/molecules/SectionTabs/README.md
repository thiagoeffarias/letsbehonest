Navegação dentro da página: chips que ficam **fixos no topo** (`position: sticky`) e levam às secções por âncora. Props: `items` `[{label, id | href, current}]`, `label` (nome acessível).

- Scroll horizontal quando não cabem todos; o `current` leva realce vermelho suave.
- Usar em páginas longas em mobile (Metodologia, resultado da calculadora). Cada item aponta para o `id` de uma secção.
