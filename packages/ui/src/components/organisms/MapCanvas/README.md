Cartograma esquemático. Props: `metric` (`price`, `change`, `excess`), `selected` `[linha, coluna]` ou `null`, `size`, `note`, `app` (mobile: ocupa o ecrã, sem cantos), `layers` (barra de camadas sobre o mapa, com `MetricTabs` em scroll), `panned` (desloca o mapa quando a folha está aberta), `children` (`LegendScale`).

- Em mobile o mapa é um ecrã de aplicação: camadas em chips por cima, legenda compacta e folha inferior. É um espaço reservado: no site será o mapa MapLibre.
