Folha inferior de mobile com três alturas. `snap`: `peek` (título e dois números), `half` (resumo da zona com botão) e `full` (tudo, com scroll). Props: `snap`, `label`, `inline`.

- No mapa, a folha em `peek` deixa a zona selecionada visível; em `half` o mapa desloca-se (`panned`) para a zona não ficar tapada.
