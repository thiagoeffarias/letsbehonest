Rodapé de página. Em desktop: missão, navegação, fontes de dados oficiais e aviso legal. Com `compact` (mobile): marca, uma linha de ligações e um `Accordion` "Fontes de dados e aviso legal" (recolhido). Props: `compact`, `mapHref`, `calcHref`, `methodHref`, `privacyHref`.

- O aviso diz que é uma estimativa por acessibilidade e não aconselhamento nem avaliação oficial.
- Os ecrãs de mapa em mobile não têm rodapé (ecrã de aplicação): chega-se a ele pelo menu.

- A versão compacta inclui os chips de idioma; todo o texto vem de chaves (`footer.*`, `nav.*`).
