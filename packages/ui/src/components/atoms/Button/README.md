Ação do utilizador. `variant`: `primary` (vermelho, uma por vista), `secondary`, `ghost`. `size`: `sm`, `md` (44px), `lg` (48px). `iconOnly` para botão só com ícone (obriga a `ariaLabel`; alvo de 44px).

- `icon` e `iconEnd` aceitam nomes de `Icon`. Com `href` renderiza uma ligação com o mesmo aspeto. `fullWidth` em mobile.
- Estados: hover, premido, foco (anel `color-focus`), desativado.
