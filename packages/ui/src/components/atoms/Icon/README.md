Ícone linear de 2px, herda `currentColor`. Use `name` do conjunto: `arrow-up`, `arrow-down`, `search`, `info`, `alert`, `map-pin`, `check`, `chevron-down`, `close`, `external`.

- Tamanho `md` (`size-icon-md`) na interface, `lg` (`size-icon-lg`) em veredictos.
- Ícone decorativo: sem `label` (fica `aria-hidden`). Ícone sozinho com significado: passe `label`.
- A cor vem do texto que o rodeia; nos veredictos use `color-verdict-above` ou `color-verdict-below` no elemento pai.
