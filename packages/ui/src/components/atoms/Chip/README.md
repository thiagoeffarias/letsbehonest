Filtro alternável (tipologia, métrica). `selected` mostra fundo `color-accent-subtle`, contorno `color-accent` e um ✓: o estado nunca depende só da cor.

- Use dentro de um grupo com `role="group"` e rótulo (`TypologyFilter`).
- `size="md"` (44px) em mobile e em ecrãs tácteis; `size="sm"` (36px) em desktop.
- Em mobile o grupo pode fazer scroll horizontal; cada chip mantém a largura do conteúdo.
