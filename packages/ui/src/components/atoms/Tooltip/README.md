Explicação curta (≤ 120 caracteres) que aparece ao passar o rato ou ao focar o filho. `content` é o texto; `open` força a visibilidade (usado em previews).

- O filho tem de ser focável (botão, ligação) e referir o tooltip com `aria-describedby` = `id`.
- Em mobile não depende de hover: o texto crítico deve estar visível na página (ex.: `SourceNote`).
