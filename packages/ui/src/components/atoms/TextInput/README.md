Campo de texto de 48px com contorno `color-border-strong`. Props: `id`, `value`/`defaultValue`, `placeholder`, `inputMode` (`numeric` para preço e área), `invalid`, `disabled`, `onChange`.

- Emparelhe sempre com `Label` (ver `FormField`).
- `invalid` altera o contorno para `color-verdict-above`; mostre também uma mensagem de texto.
- Largura 100% do contentor; defina a largura no layout, não no campo.
