Aplica um estilo tipográfico do Design System. `variant` = `display-xl`, `display-lg`, `display-md`, `body`, `body-strong`, `label`, `small`, `caption`, `figure-lg`, `figure-md`, `figure`.

- `as` muda a etiqueta HTML sem mudar o estilo; mantenha a hierarquia de títulos (um `h1` por página).
- `tone`: `secondary` (notas e fontes), `accent`, `above`, `below`. Não use `accent` em texto pequeno.
- Números de preços e percentagens usam sempre `figure*` (mono, alinhados).
- Em mobile use `display-md` e `figure-md` em vez de `display-lg` e `figure-lg`.
